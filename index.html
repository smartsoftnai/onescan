QR Code Safety

Understanding what is behind a QR code can help you make a more informed decision before opening a link.

What does a QR code scanner do?

A QR code scanner reads the information stored in a QR code and can display its content. OneScan is designed to give users additional context about scanned content before they interact with it.

How can I check a QR code before opening the link?

Scan the QR code with OneScan to view the resulting content and get additional information about the link. This can help you understand where a QR code leads before you open it.

Why should I be careful with QR code links?

A QR code can contain a URL that leads to a website. Because the destination may not be obvious from the QR image itself, reviewing the resulting link before interacting with it can provide an additional safety check.
